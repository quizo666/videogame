# Общие проекты, стартовое меню и галерея

После запуска PixelForge Studio открывается главная страница. Здесь можно создать новый проект, открыть .pfstudio или выбрать запись в «Недавних проектах». Кнопка «Главная» доступна и из редактора; «Продолжить текущий» возвращает к открытой работе.

## Один файл всей работы

Верхняя панель общая для всех вкладок:

- «Новый» — новый пустой проект;
- «Открыть» / Ctrl+O — открыть .pfstudio;
- «Сохранить» / Ctrl+S — сохранить всю работу;
- «Сохранить как» / Ctrl+Shift+S — сохранить отдельную копию;
- «Галерея» — перейти к библиотеке фонов.

Файл .pfstudio содержит:

1. Катсцену, порядок и имена слоёв, метки, трансформации, время, анимации, яркость, стабилизацию и настройки экспорта.
2. Все исходные и обработанные кадры вкладки спрайтов, включая ручное рисование и стирание.
3. Текущий редактируемый фон: исходное фото, пиксельную основу, маски и настройки движения.
4. Редактируемые фоны галереи, использованные в этой катсцене, и текущий фон.
5. Исходный видеофайл вкладки спрайтов, если он доступен на момент сохранения (до 2 ГБ).
6. Активную вкладку, позицию курсора монтажа, выбранные слой и область фона, текущий кадр спрайтов и фона.

При открытии ресурсы восстанавливаются из файла; оригинальные PNG, фото и видео не требуется выбирать заново. Уже извлечённые кадры входят в проект даже при недоступном исходном видео. История отмены и запущенное воспроизведение не сохраняются.

Проект можно перенести на другой компьютер вместе с приложением. Общая галерея целиком в каждый проект не копируется: внутрь включаются связанные и используемые фоны. Слои содержат свои изображения, поэтому монтаж не зависит от внешних файлов экспорта.

Сохранение сначала создаёт временную копию и заменяет прежний проект после успеха. Повреждённый файл при открытии не заменяет текущую работу. Список недавних проектов обновляется после сохранения и успешного открытия; он не является копией самих файлов. Если файл перемещён, откройте его через «Открыть», чтобы обновить путь.

## Галерея фонов

Вкладка «04 · Галерея фонов» общая для всех проектов приложения. Есть миниатюры, поиск по имени, размеры, длительность и FPS.

Когда вы создаёте или меняете готовый фон в третьей вкладке, через короткую паузу он автоматически сохраняется в библиотеку вместе с фото и масками. «В галерею» сохраняет его немедленно. Сохранение отдельного .bgscene, экспорт и передача в монтаж также сохраняют фон в галерее.

- «Открыть» загружает фон с масками в редактор; изменения обновляют ту же запись.
- «В монтаж» добавляет его нижним слоем текущей катсцены.
- «Создать копию» создаёт отдельный вариант, чтобы исходный фон остался в библиотеке.
- «Импорт .bgscene» добавляет ранее сохранённые фоны; можно выбрать несколько файлов.

Новая фотография и новый демо-фон получают новую запись. Изменения параметров того же фона обновляют существующую запись. Чтобы сохранить два варианта, сначала создайте копию.

Библиотека хранится в library/backgrounds рядом с PixelForge.exe. При первом запуске существующие .bgscene из examples, exports и projects внутри папки приложения подхватываются в галерею. Фоны из других папок можно добавить кнопкой импорта. Это не облачный сервис; данные находятся на этом компьютере.

При открытии .pfstudio использованные фоны восстанавливаются в библиотеке автоматически. Если в галерее уже есть другая, более новая редакция того же фона, импортируется отдельная копия: прежняя запись не перезаписывается.

Галерея сохраняет фоны автоматически, а весь проект Studio сохраняется по Ctrl+S. Поэтому отказ сохранять проект при закрытии не отменяет уже записанные изменения общей галереи.

## Старые файлы

.pxf, .cutscene и .bgscene по-прежнему открываются в соответствующих вкладках как отдельные документы. Если работа была создана в предыдущей версии, один раз откройте её части, затем сохраните общий .pfstudio. После этого всё открывается одним действием из начального меню. Перед перезапуском старой работающей версии сохраните текущие документы: замена EXE не переносит содержимое её памяти автоматически.

## Проверки и структура

Проверки: PixelForge.exe --studio-test <абсолютная папка>. Используется отдельная тестовая библиотека; проверяются автоматическое сохранение, миниатюры, все документы в одном архиве, восстановление после удаления исходного видео и очистки галереи, сохранность более новой редакции фона, отказ повреждённого открытия, сохранность прежнего файла при неудачной записи, недавние проекты и компоновка главного меню/галереи. Отчёт: studio-checks.txt.

.pfstudio — ZIP с studio.json, scene.cutscene, sprites.bin, background.bgscene при наличии фото, используемыми gallery/*.bgscene и встроенным source/video.*. Старые самостоятельные форматы остаются совместимыми. Проекты могут быть большими, если внутри много исходных кадров или видео.

Код: src/WorkspaceStorage.cs, src/WorkspaceBridge.cs, src/WorkspaceShell.cs, src/BackgroundGalleryView.cs. Настройки недавних файлов: settings/recent-projects.json.
